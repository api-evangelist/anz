# Australia and New Zealand Banking Group (ANZ)

> ANZ is one of Australia's "Big Four" banks and a designated Consumer Data Right (CDR) data holder. It exposes a public, unauthenticated Product Reference Data (PRD) API conforming to the DSB Consumer Data Standards, on two brands (ANZ and ANZ Plus). All consumer data sharing beyond product reference data is gated behind the CDR accredited-data-recipient (ADR) OAuth2/FAPI + mTLS model.

## APIs

- [ANZ CDR Product Reference Data API](https://www.anz.com.au/support/legal/anz-apis/): Public products list + detail. Base https://api.anz/cds-au/v1/banking/products
- [ANZ Plus CDR Product Reference Data API](https://www.anz.com.au/support/legal/anz-apis/): Same contract, ANZ Plus brand. Base https://cdr.apix.anz/cds-au/v1/banking/products
